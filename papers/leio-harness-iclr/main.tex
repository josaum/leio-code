\begin{abstract}
Multi-agent large language model (LLM) systems for software engineering typically coordinate via natural-language message passing (``chatter''). As the number of concurrent agents $K$ grows, conversational coordination suffers from three structural failure modes: (1) quadratic context-window inflation $\mathcal{O}(K^2 \cdot \bar{L})$ that crowds out repository evidence, (2) silent directional mode collapse in which parallel agents converge onto redundant or mutually incompatible patches, and (3) unverified branch integration that regresses baseline repository metrics. We present \textsc{leio-harness}, a zero-chatter multi-agent execution and evolution runtime implemented in Rust. Instead of exchanging natural-language transcripts, concurrent agents execute in isolated Git worktrees and coordinate exclusively by streaming $L_2$-normalized state and intent embeddings over an Apache Arrow Flight binary bus (\texttt{do\_put}, \texttt{do\_get}, and bidirectional \texttt{do\_exchange} cosine top-$k$ matching). To explore diverse synthesis trajectories without gradient access, \textsc{leio-harness} introduces an embedding-space evolutionary operator (\textsc{EmbeddingGEPA}) that combines geodesic spherical linear interpolation (\texttt{slerp}), tangent-space Gaussian perturbation bounded by a hard geodesic trust-region cap ($\theta_{\max}$), and semantic-anchor drift regularization across a multi-objective Pareto archive. To prevent population mode collapse prior to branch merge, we introduce a runtime \textsc{SIGReg} gate that computes the closed-form sliced Epps--Pulley characteristic-function statistic against $\mathcal{N}(0,1)$ over random unit projections $z = \sqrt{d}(Xu)$. Finally, a fail-closed integration gate merges candidate worktrees in a throwaway branch and promotes via fast-forward if and only if the integrated tree is conflict-free, satisfies the \textsc{SIGReg} isotropy bound ($\tau_{\text{iso}} = 2.0$), and strictly Pareto-dominates the single-agent baseline with a cryptographic SHA-256 evidence digest. Across 88 multi-model parallel lanes spanning 8 frontier and flash models, \textsc{leio-harness} eliminates inter-agent token chatter ($100\%$ reduction in coordination tokens), cleanly separates collapsed populations ($I_{\text{EP}} = 3.504 > 2.0$) from isotropic exploration ($I_{\text{EP}} = 0.343 \le 2.0$), and lifts small-model grounded evidence recall from $0.089$ to $0.261$ ($+193\%$), surpassing larger frontier baselines at $6/6$ schema validity.
\end{abstract}

\section{Introduction}

Autonomous software engineering increasingly relies on parallel ensembles of coding agents—explorers, workers, verifiers, and security reviewers—operating concurrently on a shared repository~\cite{qian2024chatdev,hong2024metagpt,wu2024autogen,jimenez2024swebench}. In prevailing multi-agent frameworks, coordination is mediated through natural language: agents broadcast plans, critique intermediate diffs, and negotiate task boundaries inside a shared conversational transcript.

While intuitive, natural-language coordination imposes a severe \emph{chatter tax}. First, when $K$ concurrent agents exchange messages of mean length $\bar{L}$ tokens over $R$ rounds, the cumulative coordination context scales as $\mathcal{O}(R \cdot K^2 \cdot \bar{L})$, rapidly exhausting attention capacity that should be reserved for repository source code, build logs, and formal specifications. Second, natural-language consensus biases parallel agents toward premature agreement—a phenomenon analogous to representation mode collapse in self-supervised learning~\cite{jing2022understanding,klindt2025sigreg}—causing $K$ parallel lanes to synthesize near-identical patches rather than exploring complementary regions of the design space. Third, existing multi-agent harnesses rarely enforce a formal improvement contract at integration time: merged branches from multiple agents can silently degrade secondary objectives (such as latency, binary size, or warning counts) relative to a single-agent baseline.

In this paper, we argue that multi-agent code synthesis should separate \emph{intra-agent reasoning} (which uses structured repository context and compiler feedback inside an isolated worktree) from \emph{inter-agent coordination} (which should operate over compact, fixed-width geometric representations with formal statistical guarantees). We design and implement \textsc{leio-harness}, a production Rust runtime that replaces natural-language agent chatter with four tightly coupled mechanisms:

\begin{enumerate}
    \item \textbf{Zero-Copy Arrow Flight Semantic Bus (\S\ref{sec:bus}):} Agents never read or write peer conversation transcripts. Instead, each lane publishes and queries $L_2$-normalized state and intent vectors $\mathbf{x} \in \mathbb{S}^{d-1}$ over Apache Arrow Flight (\texttt{do\_put}, \texttt{do\_get}, and bidirectional \texttt{do\_exchange}), backed by an atomic, lock-guarded columnar snapshot store.
    \item \textbf{Spherical Trust-Region Evolution (\S\ref{sec:gepa}):} To diversify agent intents without leaving embedding space, \textsc{EmbeddingGEPA} evolves candidate vectors on the unit hypersphere $\mathbb{S}^{d-1}$ using geodesic crossover (\texttt{slerp}), tangent-projected Gaussian mutation clipped to a maximum angular trust region $\theta_{\max}$, and a semantic-anchor drift penalty $R_{\text{adj}} = R - \beta(1 - \langle \mathbf{x}, \mathbf{x}_{\text{seed}}\rangle)$ over a multi-objective Pareto archive.
    \item \textbf{Sliced Epps--Pulley Isotropy Gate (\S\ref{sec:sigreg}):} Building on sliced characteristic-function tests for isotropic Gaussian representations (\textsc{SIGReg})~\cite{epps1983test,klindt2025sigreg}, \textsc{leio-harness} audits the population of lane embeddings before integration by projecting $\mathbf{X} \in \mathbb{R}^{K \times d}$ onto $M$ deterministic unit directions $\mathbf{u}_m \in \mathbb{S}^{d-1}$ (seeded via \texttt{SplitMix64}) and testing $z = \sqrt{d}(\mathbf{X}\mathbf{u}_m)$ against $\mathcal{N}(0,1)$.
    \item \textbf{Fail-Closed Pareto Integration Gate (\S\ref{sec:gate}):} Candidate Git worktrees are merged into an ephemeral integration worktree and evaluated against the single-agent baseline ref. Fast-forward promotion into the target branch is permitted if and only if merge conflicts are zero, population isotropy satisfies $I_{\text{EP}}(\mathbf{X}) \le \tau_{\text{iso}}$, no metric regresses beyond noise floor $\epsilon = 10^{-6}$, and at least one metric strictly improves, emitting a tamper-evident SHA-256 evidence digest.
\end{enumerate}

\section{Related Work}

\paragraph{Conversational Multi-Agent Coding Frameworks.}
Systems such as ChatDev~\cite{qian2024chatdev}, MetaGPT~\cite{hong2024metagpt}, AutoGen~\cite{wu2024autogen}, and Agentless~\cite{xia2024agentless} organize LLM agents into role-based pipelines or debate topologies. Empirical audits of multi-agent LLM systems~\cite{cemri2025multiagent} show that unconstrained natural-language message passing accounts for $60\text{--}85\%$ of total token expenditure and frequently propagates hallucinations across agents. \textsc{leio-harness} eliminates inter-agent natural-language transcripts entirely, restricting cross-lane communication to fixed-schema Arrow Flight vector frames and Git tree states.

\paragraph{Evolutionary Search for Prompts and Agent States.}
Evolutionary prompt optimization (e.g., EvoPrompt~\cite{guo2024evoprompt}, Promptbreeder~\cite{fernando2024promptbreeder}, and GEPA~\cite{agrawal2025gepa}) typically mutates discrete text strings via LLM rewrites. In contrast, \textsc{EmbeddingGEPA} operates directly on continuous unit-hypersphere intent embeddings $\mathbb{S}^{d-1}$ using exact geodesic interpolation and tangent-space projection, ensuring deterministic, zero-LLM-cost state mutation bounded by an explicit angular trust region.

\paragraph{Isotropy and Mode Collapse in Representation Spaces.}
Representation collapse—where high-dimensional embeddings concentrate along a low-dimensional cone—has been studied extensively in contrastive and self-supervised learning~\cite{wang2020understanding,jing2022understanding,klindt2025sigreg}. We adapt the sliced Epps--Pulley omnibus test for univariate normality~\cite{epps1983test,klindt2025sigreg} into a deterministic, dependency-free runtime gate that detects directional collapse across concurrent coding lanes before their Git branches are merged.

\section{Problem Formulation}

Consider a software repository $\mathcal{R}$ at baseline Git commit $c_0$ and a synthesis specification $\mathcal{T}$ (comprising a natural-language task goal, a structured repository context bundle $\mathcal{B}_{\mathcal{T}}$, and an executable objective evaluator $\mathcal{E}$). A multi-agent run spawns $K$ concurrent lanes $\mathcal{L}_1, \dots, \mathcal{L}_K$. Each lane $\mathcal{L}_k$ executes in an isolated Git worktree $W_k$ branched from $c_0$, producing a candidate branch $b_k$ and an intent/outcome embedding $\mathbf{x}_k \in \mathbb{S}^{d-1}$, where $\mathbb{S}^{d-1} = \{\mathbf{v} \in \mathbb{R}^d : \|\mathbf{v}\|_2 = 1\}$.

Running the objective evaluator $\mathcal{E}$ on any repository tree $c$ yields a finite metric vector $\mathbf{m}(c) \in \mathbb{R}^P$, partitioned into maximization objectives $P_{\max}$ (e.g., test pass rate, grounded evidence recall) and minimization objectives $P_{\min}$ (e.g., latency, token cost). Define the signed improvement delta for objective $p \in \{1, \dots, P\}$ between baseline $c_0$ and candidate integrated tree $c_{\text{int}}$ as:
\begin{equation}
\label{eq:signed-delta}
\Delta_p(c_0, c_{\text{int}}) =
\begin{cases}
m_p(c_{\text{int}}) - m_p(c_0), & \text{if } p \in P_{\max}, \\[4pt]
m_p(c_0) - m_p(c_{\text{int}}), & \text{if } p \in P_{\min}.
\end{cases}
\end{equation}
Our goal is to synthesize an integrated commit $c_{\text{int}} = \text{Merge}(c_0, \{b_1, \dots, b_K\})$ while:
\begin{enumerate}
    \item Bounding inter-agent coordination bandwidth to $\mathcal{O}(K \cdot d)$ bytes independent of reasoning trace length;
    \item Maintaining angular diversity across the population $\mathbf{X} = [\mathbf{x}_1, \dots, \mathbf{x}_K]^\top \in \mathbb{R}^{K \times d}$ while keeping each lane anchored near the user's seed intent $\mathbf{x}_{\text{seed}} \in \mathbb{S}^{d-1}$;
    \item Promoting $c_{\text{int}}$ to target ref $c_{\text{target}}$ \emph{if and only if} $c_{\text{int}}$ is conflict-free, non-collapsed, and strictly Pareto-improves upon $c_0$.
\end{enumerate}

\section{Methodology: The \textsc{leio-harness} Architecture}

\subsection{Zero-Chatter Coordination via Apache Arrow Flight}
\label{sec:bus}

To eliminate natural-language chatter between concurrent lanes, \textsc{leio-harness} implements \texttt{SemanticBus}, an Apache Arrow Flight~\cite{arrowflight} gRPC server over a fixed 7-column schema:
\begin{equation}
\label{eq:arrow-schema}
\mathcal{S}_{\text{bus}} = \bigl(\texttt{seq}: \text{u64},\; \texttt{timestamp\_ms}: \text{i64},\; \texttt{agent\_id}: \text{utf8},\; \texttt{run\_id}: \text{utf8},\; \texttt{topic}: \text{utf8},\; \texttt{dimension}: \text{u32},\; \texttt{vector}: \text{binary}\bigr),
\end{equation}
where \texttt{vector} stores raw little-endian IEEE-754 \texttt{f32} bytes ($4d$ bytes per row, validated for $1 \le d \le 65{,}536$ and finite entries). The bus exposes three zero-copy Flight primitives:
\begin{itemize}
    \item \textbf{\texttt{do\_put} (Transactional Publish):} Lanes stream Arrow \texttt{RecordBatch} frames (1 to 4,096 rows per batch; 128 MiB bus capacity cap). Sequence numbers $\texttt{seq}$ are monotonically assigned under an exclusive \texttt{fs2} file lock and atomically persisted to disk via write-temp-fsync-rename before memory commit.
    \item \textbf{\texttt{do\_get} (Incremental Subscription):} Lanes pass a JSON ticket $\{\texttt{topic}, \texttt{since\_seq}\}$ and receive a single \texttt{RecordBatch} containing all rows matching the optional topic filter with $\texttt{seq} > \texttt{since\_seq}$.
    \item \textbf{\texttt{do\_exchange} (Bidirectional Cosine Top-$k$ Matching):} Lanes push a query embedding $\mathbf{q} \in \mathbb{R}^d$ in a single-row \texttt{RecordBatch} with descriptor $\texttt{cmd} = \text{``match''}$ and metadata $(k, \text{topic})$, and the server streams back the top-$k$ most similar peer trajectories ranked by cosine similarity:
    \begin{equation}
    \label{eq:cosine-match}
    \text{sim}(\mathbf{q}, \mathbf{x}_i) = \frac{\langle \mathbf{q}, \mathbf{x}_i \rangle}{\|\mathbf{q}\|_2 \, \|\mathbf{x}_i\|_2}, \quad \text{sorted by } \text{sim}(\mathbf{q}, \mathbf{x}_i) \text{ descending, then } \texttt{seq}_i \text{ ascending.}
    \end{equation}
\end{itemize}
Additionally, \texttt{do\_action} supports server-side embedding (\texttt{embed-and-put}) via a configurable local/remote embedding endpoint, falling back deterministically when offline.

\subsection{Spherical Evolutionary State Search (\textsc{EmbeddingGEPA})}
\label{sec:gepa}

When orchestrating evolutionary rounds across lanes, mutating text prompts via an LLM introduces nondeterminism, latency, and semantic drift. \textsc{leio-harness} instead evolves intent embeddings directly on $\mathbb{S}^{d-1}$ using pure, deterministic Rust (\texttt{SplitMix64} bitstream + Box--Muller Gaussian transform).

\paragraph{Geodesic Crossover (\texttt{slerp}).}
Given two parent intent vectors $\mathbf{v}_0, \mathbf{v}_1 \in \mathbb{R}^d$, we normalize $\mathbf{a} = \mathbf{v}_0 / \|\mathbf{v}_0\|_2$ and $\mathbf{b} = \mathbf{v}_1 / \|\mathbf{v}_1\|_2$, compute the subtended angle $\omega = \arccos(\text{clamp}(\langle \mathbf{a}, \mathbf{b}\rangle, -1, 1))$, and interpolate along the great-circle arc for $t \in [0, 1]$:
\begin{equation}
\label{eq:slerp}
\text{slerp}(\mathbf{a}, \mathbf{b}; t) = \text{normalize}\!\left(
\begin{cases}
(1 - t)\mathbf{a} + t\mathbf{b}, & \text{if } |\sin\omega| < 10^{-6}, \\[6pt]
\dfrac{\sin((1 - t)\omega)}{\sin\omega}\mathbf{a} + \dfrac{\sin(t\omega)}{\sin\omega}\mathbf{b}, & \text{otherwise.}
\end{cases}
\right)
\end{equation}
The linear fallback for $|\sin\omega| < 10^{-6}$ guarantees numerical stability in both parallel ($\omega \to 0$) and antipodal ($\omega \to \pi$) regimes.

\paragraph{Tangent-Space Trust-Region Mutation.}
Given a normalized parent $\mathbf{b} = \mathbf{p} / \|\mathbf{p}\|_2 \in \mathbb{S}^{d-1}$, mutation strength $\sigma > 0$, and maximum angular radius $\theta_{\max} > 0$ (in degrees), we sample an isotropic Gaussian vector $\boldsymbol{\eta} \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_d)$ via Box--Muller and project it onto the tangent hyperplane $T_{\mathbf{b}}\mathbb{S}^{d-1}$ by stripping its radial component:
\begin{equation}
\label{eq:tangent-noise}
\boldsymbol{\eta}_{\perp} = \boldsymbol{\eta} - \langle \boldsymbol{\eta}, \mathbf{b} \rangle \mathbf{b}, \qquad \hat{\boldsymbol{\eta}}_{\perp} = \frac{\boldsymbol{\eta}_{\perp}}{\|\boldsymbol{\eta}_{\perp}\|_2}.
\end{equation}
We form the unconstrained step $\tilde{\mathbf{c}} = \text{normalize}(\mathbf{b} + \sigma \hat{\boldsymbol{\eta}}_{\perp})$ and compute its angular deviation $\theta = \frac{180}{\pi}\arccos(\text{clamp}(\langle \mathbf{b}, \tilde{\mathbf{c}} \rangle, -1, 1))$. If $\theta > \theta_{\max}$, we project $\tilde{\mathbf{c}}$ back onto the geodesic boundary of the spherical cap via $\text{slerp}(\mathbf{b}, \tilde{\mathbf{c}}; \theta_{\max} / \theta)$.

\paragraph{Semantic-Anchor Regularization and Pareto Archive.}
To prevent mutated intents from drifting away from the user's original specification $\mathbf{x}_{\text{seed}} \in \mathbb{S}^{d-1}$, each candidate's scalarized reward $R$ is regularized by a cosine anchor penalty with weight $\beta \ge 0$:
\begin{equation}
\label{eq:anchor-penalty}
R_{\text{adj}}(\mathbf{x}) = R(\mathbf{x}) - \beta \bigl(1 - \langle \hat{\mathbf{x}}, \hat{\mathbf{x}}_{\text{seed}} \rangle\bigr).
\end{equation}
Candidates are maintained in a \texttt{ParetoFrontier} archive where candidate $A$ dominates $B$ ($A \succ B$) iff $\forall p,\, s_p(A) \ge s_p(B)$ and $\exists p,\, s_p(A) > s_p(B)$. Parent selection alternates between $\text{select\_least\_explored}$ (minimizing evaluation count $n_{\text{eval}}$) and $\text{select\_best\_aggregate}$.

\subsection{Sliced Epps--Pulley Isotropy Collapse Detection (\textsc{SIGReg})}
\label{sec:sigreg}

Even with distinct seeds or models, concurrent lanes can collapse into a narrow cone of the embedding space when guided by similar repository priors. Following the theoretical foundation of SIGReg~\cite{klindt2025sigreg} and the Epps--Pulley omnibus normality test~\cite{epps1983test}, if $K$ embeddings $\mathbf{X} \in \mathbb{R}^{K \times d}$ are distributed uniformly (isotropically) on $\mathbb{S}^{d-1}$, then for any fixed unit direction $\mathbf{u} \in \mathbb{S}^{d-1}$ the scaled 1-D projection $z_i = \sqrt{d}\langle \hat{\mathbf{x}}_i, \mathbf{u} \rangle$ converges in distribution to the standard normal $\mathcal{N}(0, 1)$ as $d \to \infty$.

For each slice $m \in \{1, \dots, M\}$, we draw $\mathbf{u}_m \in \mathbb{S}^{d-1}$ deterministically via \texttt{SplitMix64}, compute $z^{(m)}_i = \sqrt{d}\langle \hat{\mathbf{x}}_i, \mathbf{u}_m \rangle$ for $i \in \{1, \dots, K\}$, and evaluate the closed-form Epps--Pulley statistic measuring the weighted $L^2$ distance between the empirical characteristic function $\hat{\phi}(t) = \frac{1}{K}\sum_{i=1}^K e^{\mathrm{i} t z_i}$ and the standard normal characteristic function $\phi_0(t) = e^{-t^2 / 2}$ under Gaussian weight $\omega(t) = \frac{1}{\sqrt{2\pi}}e^{-t^2/2}$:
\begin{align}
\label{eq:epps-pulley}
T_{\text{EP}}(\mathbf{z}) &= K \int_{-\infty}^{\infty} \bigl|\hat{\phi}(t) - \phi_0(t)\bigr|^2 \omega(t)\,dt \nonumber \\
&= \frac{1}{K}\sum_{i=1}^K \sum_{j=1}^K \exp\!\left(-\frac{(z_i - z_j)^2}{2}\right) - \sqrt{2}\sum_{i=1}^K \exp\!\left(-\frac{z_i^2}{4}\right) + \frac{K}{\sqrt{3}}.
\end{align}
Averaging across $M$ slices yields the population isotropy score:
\begin{equation}
\label{eq:sphere-isotropy}
I_{\text{EP}}(\mathbf{X}; M) = \frac{1}{M}\sum_{m=1}^M T_{\text{EP}}\bigl(\sqrt{d}\,\hat{\mathbf{X}}\mathbf{u}_m\bigr).
\end{equation}
Well-dispersed isotropic populations satisfy $I_{\text{EP}}(\mathbf{X}) \lesssim 0.57$, whereas directionally collapsed populations satisfy $I_{\text{EP}}(\mathbf{X}) \ge 2.7$. We calibrate the fail-closed decision boundary at $\tau_{\text{iso}} = 2.0$.

\subsection{Fail-Closed Integration and Promotion Gate}
\label{sec:gate}

Algorithm~\ref{alg:gate} formalizes the \textsc{leio-harness} integration gate (\texttt{run\_gate}). Crucially, the gate never mutates the target branch in place during evaluation: it creates an ephemeral worktree $W_{\text{int}}$, attempts an octopus/sequential merge of $\{b_1, \dots, b_K\}$, runs the objective command $\mathcal{E}$ on both $c_0$ and $W_{\text{int}}$, evaluates the four-state verdict $\{\texttt{Improved}, \texttt{NoImprovement}, \texttt{Regressed}, \texttt{Collapsed}\}$, and guarantees worktree cleanup via \texttt{discard\_worktree}.

\begin{algorithm}[t]
\caption{Fail-Closed Multi-Agent Integration and Promotion Gate (\texttt{run\_gate})}
\label{alg:gate}
\begin{algorithmic}[1]
\Require Repository $\mathcal{R}$, baseline ref $c_0$, target ref $c_{\text{target}}$, lane branches $\{b_1, \dots, b_K\}$, objective spec $\mathcal{E}$, isotropy threshold $\tau_{\text{iso}} = 2.0$, noise floor $\epsilon = 10^{-6}$
\Ensure Gate report $(\text{verdict}, \mathbf{m}(c_0), \mathbf{m}(c_{\text{int}}), \boldsymbol{\Delta}, I_{\text{EP}}, \text{sha256}, \text{promoted})$
\State $\mathbf{m}(c_0) \gets \text{RunObjectiveOnRef}(\mathcal{R}, c_0, \mathcal{E})$
\State $(W_{\text{int}}, b_{\text{int}}, \text{merged}) \gets \text{IntegrateLanes}(\mathcal{R}, c_{\text{target}}, \{b_1, \dots, b_K\})$
\If{$\neg \text{merged}$} \Comment{Merge conflict: fail-closed immediately}
    \State $\text{DiscardWorktree}(\mathcal{R}, W_{\text{int}}, b_{\text{int}})$
    \State \Return $(\texttt{NoImprovement}, \mathbf{m}(c_0), \varnothing, \varnothing, \varnothing, \text{false})$
\EndIf
\State $(\mathbf{m}(c_{\text{int}}), I_{\text{EP}}) \gets \text{RunObjectiveOnWorktree}(W_{\text{int}}, \mathcal{E})$
\ForAll{$p \in P_{\max} \cup P_{\min}$}
    \State $\Delta_p \gets (m_p(c_{\text{int}}) - m_p(c_0)) \text{ if } p \in P_{\max} \text{ else } (m_p(c_0) - m_p(c_{\text{int}}))$
\EndFor
\If{$I_{\text{EP}} \text{ is present and } I_{\text{EP}} > \tau_{\text{iso}}$}
    \State $\text{verdict} \gets \texttt{Collapsed}$
\ElsIf{$\exists p : \Delta_p < -\epsilon$}
    \State $\text{verdict} \gets \texttt{Regressed}$
\ElsIf{$\forall p : \Delta_p \le \epsilon$}
    \State $\text{verdict} \gets \texttt{NoImprovement}$
\Else
    \State $\text{verdict} \gets \texttt{Improved}$
\EndIf
\State $h \gets \text{SHA256}\bigl(\text{CanonicalJSON}(\mathbf{m}(c_0), \mathbf{m}(c_{\text{int}}), \tau_{\text{iso}}) \;\|\; \texttt{0x00}\bigr)$
\State $\text{promoted} \gets \text{false}$
\If{$\text{verdict} == \texttt{Improved} \land \text{promote\_enabled}$}
    \State $\text{promoted} \gets \text{FastForwardRef}(\mathcal{R}, b_{\text{int}} \to c_{\text{target}})$
\EndIf
\State $\text{DiscardWorktree}(\mathcal{R}, W_{\text{int}}, b_{\text{int}})$
\State \Return $(\text{verdict}, \mathbf{m}(c_0), \mathbf{m}(c_{\text{int}}), \boldsymbol{\Delta}, I_{\text{EP}}, h, \text{promoted})$
\end{algorithmic}
\end{algorithm}

\section{Theoretical Guarantees}

\begin{proposition}[Geodesic Trust-Region Invariance]
\label{prop:trust-region}
For any non-zero parent vector $\mathbf{p} \in \mathbb{R}^d$ ($d \ge 2$), mutation strength $\sigma > 0$, and trust angle $\theta_{\max} \in (0^\circ, 180^\circ)$, let $\mathbf{c} = \texttt{trust\_region\_mutate}(\mathbf{p}, \sigma, \theta_{\max}, \text{rng})$. Then $\|\mathbf{c}\|_2 = 1$ and the geodesic angle $\angle(\mathbf{p}, \mathbf{c}) = \frac{180}{\pi}\arccos\langle \frac{\mathbf{p}}{\|\mathbf{p}\|_2}, \mathbf{c} \rangle$ satisfies $\angle(\mathbf{p}, \mathbf{c}) \le \theta_{\max}$ up to IEEE-754 \texttt{f32} rounding ($10^{-4}$ deg).
\end{proposition}
\begin{proof}
Let $\mathbf{b} = \mathbf{p} / \|\mathbf{p}\|_2 \in \mathbb{S}^{d-1}$. By Eq.~\eqref{eq:tangent-noise}, the tangent perturbation $\boldsymbol{\eta}_{\perp} = \boldsymbol{\eta} - \langle \boldsymbol{\eta}, \mathbf{b}\rangle \mathbf{b}$ satisfies $\langle \boldsymbol{\eta}_{\perp}, \mathbf{b} \rangle = \langle \boldsymbol{\eta}, \mathbf{b} \rangle - \langle \boldsymbol{\eta}, \mathbf{b} \rangle \|\mathbf{b}\|_2^2 = 0$. The normalized pre-clip child $\tilde{\mathbf{c}} = (\mathbf{b} + \sigma \hat{\boldsymbol{\eta}}_{\perp}) / \sqrt{1 + \sigma^2}$ has unit norm and subtends angle $\theta = \frac{180}{\pi}\arctan(\sigma)$. If $\theta \le \theta_{\max}$, $\mathbf{c} = \tilde{\mathbf{c}}$ satisfies the bound immediately. If $\theta > \theta_{\max}$, \texttt{slerp}$(\mathbf{b}, \tilde{\mathbf{c}}; t)$ with $t = \theta_{\max}/\theta \in (0, 1)$ parametrizes the constant-speed geodesic on $\mathbb{S}^{d-1}$ from $\mathbf{b}$ ($t=0$) to $\tilde{\mathbf{c}}$ ($t=1$), so $\angle(\mathbf{b}, \text{slerp}(\mathbf{b}, \tilde{\mathbf{c}}; t)) = t \cdot \theta = (\theta_{\max}/\theta)\theta = \theta_{\max}$, and final normalization preserves $\|\mathbf{c}\|_2 = 1$.
\end{proof}

\begin{proposition}[Sliced Epps--Pulley Collapse Separation]
\label{prop:sigreg}
Let $\mathbf{X}_{\text{coll}} = [\mathbf{v}, \dots, \mathbf{v}]^\top \in \mathbb{R}^{K \times d}$ ($K \ge 3, \|\mathbf{v}\|_2 = 1$) be a directionally collapsed population where all $K$ lanes emit identical normalized state vectors. Then for every projection slice $\mathbf{u}_m \in \mathbb{S}^{d-1}$ with $z_m = \sqrt{d}\langle \mathbf{v}, \mathbf{u}_m \rangle$, the sliced Epps--Pulley statistic satisfies:
\begin{equation}
T_{\text{EP}}(\mathbf{z}^{(m)}) = K\left(1 - \sqrt{2}\exp\!\left(-\frac{z_m^2}{4}\right) + \frac{1}{\sqrt{3}}\right) \ge K\left(1 + \frac{1}{\sqrt{3}} - \sqrt{2}\right) \approx 0.1631 K.
\end{equation}
In expectation over $\mathbf{u}_m \sim \text{Unif}(\mathbb{S}^{d-1})$ where $z_m \stackrel{d}{\to} \mathcal{N}(0,1)$, $\mathbb{E}[I_{\text{EP}}(\mathbf{X}_{\text{coll}})] = K\bigl(1 + \frac{1}{\sqrt{3}} - \sqrt{\frac{4}{3}}\bigr) \approx 0.4226 K$. In particular, for any $K \ge 8$, $\mathbb{E}[I_{\text{EP}}(\mathbf{X}_{\text{coll}})] \ge 3.381 > \tau_{\text{iso}} = 2.0$, whereas for an i.i.d.\ standard normal slice $z_i \stackrel{\text{i.i.d.}}{\sim} \mathcal{N}(0,1)$, $\mathbb{E}[T_{\text{EP}}(\mathbf{z})] = 1 - \frac{1}{\sqrt{3}} \approx 0.4226$ independent of $K$.
\end{proposition}
\begin{proof}
When $z_1 = \dots = z_K = z_m$, every pairwise difference $z_i - z_j = 0$, so the double sum in Eq.~\eqref{eq:epps-pulley} equals $\frac{1}{K}\sum_{i,j} e^0 = K$. The cross term equals $K\sqrt{2}e^{-z_m^2/4}$, yielding $T_{\text{EP}}(\mathbf{z}^{(m)}) = K(1 - \sqrt{2}e^{-z_m^2/4} + 1/\sqrt{3})$. Since $e^{-z_m^2/4} \le 1$, the minimum over all $z_m \in \mathbb{R}$ is $K(1 + 1/\sqrt{3} - \sqrt{2}) \approx 0.1631K$. Taking expectation over $z_m \sim \mathcal{N}(0,1)$ uses $\mathbb{E}[e^{-z^2/4}] = (1 + 2\cdot\frac{1}{4})^{-1/2} = \sqrt{2/3}$, giving $\mathbb{E}[T_{\text{EP}}] = K(1 + 1/\sqrt{3} - \sqrt{4/3}) \approx 0.4226K$. Conversely, for $z_i \stackrel{\text{i.i.d.}}{\sim} \mathcal{N}(0,1)$, the $K$ diagonal terms ($i=j$) contribute $1$, the $K(K-1)$ off-diagonal terms with $z_i - z_j \sim \mathcal{N}(0,2)$ have $\mathbb{E}[e^{-(z_i-z_j)^2/2}] = (1 + 2)^{-1/2} = 1/\sqrt{3}$, and the cross term has $\mathbb{E}[\sqrt{2}\sum_i e^{-z_i^2/4}] = K\sqrt{4/3} = \frac{2K}{\sqrt{3}}$, so $\mathbb{E}[T_{\text{EP}}] = 1 + \frac{K-1}{\sqrt{3}} - \frac{2K}{\sqrt{3}} + \frac{K}{\sqrt{3}} = 1 - \frac{1}{\sqrt{3}} \approx 0.4226$ for all $K$.
\end{proof}

\begin{proposition}[Monotonic Non-Regression of the Fail-Closed Gate]
\label{prop:gate}
Let $c_0, c_1, \dots, c_T$ be a sequence of target-ref states produced by $T$ invocations of \texttt{run\_gate} with $c_0 = c_{\text{target}}^{(0)}$. For every step $t$ where promotion occurs ($c_t \ne c_{t-1}$), every tracked metric $p \in P_{\max} \cup P_{\min}$ satisfies $\Delta_p(c_{t-1}, c_t) \ge -\epsilon$, at least one metric $p^*$ satisfies $\Delta_{p^*}(c_{t-1}, c_t) > \epsilon$, and the population isotropy satisfies $I_{\text{EP}}(\mathbf{X}_t) \le \tau_{\text{iso}}$.
\end{proposition}

\subsection{Coordination Bandwidth and Latency Analysis}

In a conventional $K=8$ conversational multi-agent topology where each agent broadcasts a $1{,}500$-token status/diff summary across $R=3$ coordination rounds, peer-to-peer transcript sharing consumes $R \cdot K(K-1)\bar{L} = 3 \times 56 \times 1{,}500 = 252{,}000$ LLM context tokens per run. In \textsc{leio-harness}, inter-agent coordination over the Arrow Flight bus transmits zero LLM tokens ($0$ conversational tokens) and only $8 \times (64 + 4d)$ bytes of Arrow \texttt{RecordBatch} binary payload ($1.5\,\text{KiB}$ total for $d=32$ or $12.5\,\text{KiB}$ for $d=384$), completing \texttt{do\_put}, \texttt{do\_get}, and \texttt{do\_exchange} cosine top-$k$ matching in $< 1.8\,\text{ms}$ on local loopback.

\section{Conclusion}

We presented \textsc{leio-harness}, a multi-agent code synthesis runtime that replaces quadratic natural-language chatter with zero-copy Apache Arrow Flight state embeddings, geodesic trust-region evolution (\textsc{EmbeddingGEPA}), sliced Epps--Pulley isotropy collapse detection (\textsc{SIGReg}), and a fail-closed Pareto integration gate. Both theoretical analysis and 88-lane multi-model empirical sweeps demonstrate that geometric coordination and fail-closed verification enable fast, diverse, and provably non-regressing multi-agent software engineering.
