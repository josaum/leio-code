# LEIO Code for Codex

Follow [the canonical agent routing skill](../skills/leio-code/SKILL.md).
Start with local stdio `leio_code_context(task, repo_root)`, using an absolute
repository root. Use an explicit session for stateful navigation.

Install with [the one-prompt stdio guide](../docs/install-stdio.md). The optional
HTTP Apps SDK is a separate host integration and is not a local prerequisite.

See [surface gaps](../docs/MCP-SURFACE-GAP.md) and
[the wire contract](../docs/MCP-SPEC-2025-11-25.md) for supported operations.
